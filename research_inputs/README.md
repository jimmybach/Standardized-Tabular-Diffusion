# Research Inputs

This directory is a working area for papers, technical reports, benchmark specifications, notes, and other external files supplied for project discussion and review.

Materials placed here are research inputs, not authoritative project documentation. Stable conclusions and approved requirements should be incorporated into the appropriate files under `docs/`.

Before any material in this directory is committed or included in a public release, verify its provenance, redistribution rights, confidentiality, and file size. Prefer links, DOIs, and bibliographic metadata over redistributing third-party documents when permission is unclear.

Only this README is tracked by default. Other contents are intentionally ignored so maintainers can place local review material here without accidentally adding third-party papers, copied repositories, benchmark data, or confidential drafts to a commit. Project-owned conclusions, metric specifications, and provenance records belong under `docs/` or another reviewed repository path.
