## 适配边界

适配器接受一张无缺失值的单表，要求恰好一个目标、角色完整互斥、数值有限、列名对官方解析器安全。类别特征和分类目标在进入未经修改的官方标签编码器前转为字符串。缺失值必须先使用只在训练集拟合的中央填补模块。

官方构造、标签编码、行文本训练和采样调用保持不变。官方采样器只在内部行数循环结束后检查类别取值范围，因此最终可用行数可能少于请求数。适配器会针对剩余行数重复调用未修改的官方采样器，保持调用顺序与随机数流，并只在最终边界截断；连续返回零行会明确失败。适配器还约束 Python、NumPy 与 PyTorch 随机状态，隔离官方导入与输出目录，并因官方采样循环没有重试上限而在 Linux 上施加外部计时器。非 Linux 环境只有明确接受无界运行后才能采样。

官方 `torch.save` 检查点在持久化边界被替换为 safetensors、类型化 JSON 标签编码器/状态，以及完整文件清单。恢复后仍调用官方类的原始 `sample()`。危险扩展名、符号链接、清单外文件或字节变化均失败关闭。

## 强制等价用例

工作流离线构建单层 GPT-2，并在同一张 24 行全类别表上，以 0、19、73 三个种子分别训练官方直接路径和适配器路径。每个用例逐张量精确比较，重新加载安全产物，并在直接官方路径独立应用相同的精确行数边界；两条路径使用同一个编码目标分布调用未修改的官方采样器，最终要求 5 行 DataFrame 完全一致和 CSV 字节完全一致。

门槛还校验压缩包与六个源码文件身份、运行前后源码不变、精确行数和列顺序、无缺失值、安全产物，以及调用者随机数/线程状态恢复。采样超过声明的时限将失败并保留诊断证据。

## 已知边界

- 微型离线模型只证明封装等价，不证明实用质量。
- 官方解析器不能安全表达列名中的任意空格或逗号，并会丢弃格式错误的生成行。
- 数据集模型选择、训练预算、评测和资源限制仍待确定。
